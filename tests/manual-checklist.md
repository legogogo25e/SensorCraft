## 基础

- [ ] HTTPS/localhost 打开，无控制台报错。
- [ ] 首次进入出现校准门；「开始冒险」能申请运动权限。
- [ ] 「稍后」也能进入背包。
- [ ] F3 面板显示安全上下文、卡片数量、FPS。
- [ ] 左下角聊天日志出现「世界已加载」。
- [ ] 卡片墙在 390×844 与 1280×800 下无横向滚动。
- [ ] 每张卡片可聚焦并打开。

## 模块

- [ ] 摄像头：出现画面、分辨率/FPS、切换镜头、拍照、取色、亮度；返回后摄像头指示灯熄灭。
- [ ] 麦克风：波形、频谱、相对 dB、主频、音名；停止后麦克风指示灯熄灭。
- [ ] 补光灯：能检测并给出真实结论，不假装成功。
- [ ] 加速度计：授权后有 X/Y/Z、合矢量、气泡；步数可增加；重置有效。
- [ ] 陀螺仪：转动手机有角速度与旋转水晶；峰值可重置。
- [ ] 姿态与指南针：有方位、中文方向、水平气泡；无指南针时标明相对方向。
- [ ] GPS：授权后出现坐标、精度、轨迹；移动有里程；清空有效。
- [ ] 多点触控：多指同时显示编号；最大触点数增加；点靶游戏可完成 5 次。
- [ ] 扬声器/语音：播放 440Hz、切换波形、停止；TTS 朗读；语音识别不支持时说明清楚。
- [ ] 游戏手柄：连接后按键亮灭、摇杆移动；断开后回到空状态。
- [ ] 屏幕常亮：拉杆开启后系统不自动锁屏；切后台再回来能重新申请。
- [ ] WebGPU：显示适配器/特性或明确不可用。
- [ ] 手动相机：只显示真实能力；不支持时灰显并解释。
- [ ] Face ID：信息卡可展开 WebAuthn 说明。
- [ ] 人面识别：联网首次打开时读数显示 MediaPipe BlazeFace (GPU/CPU)，前置摄像头正脸出现绿框 + FACE 1 · 置信度 + 6 个关键点；切换镜头、暂停/继续、置信度滑杆、显示关键点开关、拍照带框都有效；无脸时不乱框；返回后摄像头指示灯熄灭。断网重开时应显示「肤色兜底 (离线)」而非白屏。
- [ ] YOLO 识别：联网首次打开时读数显示 ONNX Runtime Web (WASM) / YOLO26n INT8，对准人出现彩色框 + 「人 · 置信度」中文标签；工具栏模型选择器切到 YOLO11n 后重新加载并显示 YOLO11n INT8、仍能框到物体，再切回 26n 也正常，选择刷新后保留；切换镜头、暂停/继续、置信度滑杆、拍照带框都有效；空画面不乱框；返回后摄像头指示灯熄灭；断网时显示加载失败原因而非白屏。
- [ ] 反应时间：卡片墙出现「反应时间」（生物医学组）；打开后显示玩法说明 + 大目标 + 开始按钮 + 免责声明；点「开始」后提示收起、目标滚动到屏幕中央、没有新窗口/新标签，测试全程只有一个颜色目标框（待开始占位框已消失，不会出现上下两个框）；进入 3 次练习（变绿前点按显示「太早了」、变绿后点按显示毫秒数），再进 15 次计分（每次点按后也显示当次毫秒数）；完成后显示中位反应、四分位距、最快/最慢、有效次数，并列出全部 18 次（练习 + 计分，含作废原因）；抢先 4 次以上应显示「没有可比分数」而非给分数；「复制结果」能复制结果文本，「导出数据 JSON」能下载全部试次；「再测一次」可重跑；中途返回背包不报错、再打开可正常开始；无控制台报错。
- [ ] 传感器说明：打开任意卡片，标题栏状态徽章旁有「ⓘ 说明」按钮；点开后弹出教学卡，含原理、用途、数据结构表、SVG 配图、「试一试」；未解锁卡的说明含「为什么网页拿不到」；点 ✕ / 点遮罩 / 按 Esc 都只关弹窗、不关工作台；关后焦点回到「说明」按钮；无控制台报错。

## 锁定卡

- [ ] 12 张锁定卡都能打开并显示中文原因与替代方案。
- [ ] 没有一张锁定卡抛异常或显示空白。

## 异常路径

- [ ] 拒绝摄像头权限：显示可读错误与重试引导。
- [ ] 拒绝定位：显示可读错误与重试引导。
- [ ] 非 HTTPS 打开：顶部红色横幅；媒体/定位卡片给出原因。
- [ ] 摄像头被其他 App 占用：错误可读。
- [ ] 快速连续开关卡片：无重复监听、无双重绘制。
- [ ] 页面切后台再回来：不崩溃；媒体模块可重新开始。
